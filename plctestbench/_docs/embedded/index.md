# OpenPLC Studio documentation

Hello there! This is the documentation section of the core computational model of OpenPLC Studio, which is handled by [PLC Testbench](https://github.com/CIMIL/plc-testbench) Python package.

OpenPLC Studio takes care of the infamous job of having to use a programatic API. However, a lot of domain knowledge is required to use this application properly. This documentation hopefully will allow you dissipate some doubts about the algorithms offered by the app.

- [Algorithms primer](guides/models-and-metrics.md): Get to know all the built-in algorithms
- [Crossfade guide](guides/crossfades-platform.md): How fades are handled
- [AdvancedPLC guide](guides/advanced-plc-platform.md): In-depth explanation of [AdvancedPLC](reference/plc_algorithm.md#plctestbench.plc_algorithm.AdvancedPLC), the main interface for composing modular PLC algorithms
- [Custom plugins guide](guides/custom-plugins.md): Step-by-step tutorial on how to write your own module for OpenPLC Studio
- [API Reference](reference/index.md): Detailed classes, settings, parameters, and return types
